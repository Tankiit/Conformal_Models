# 🏁 CUB Gate Run: Same-Pool Check + Joint Comparison (2026-11-06)

> **Pipeline:** frozen DINOv2-base (local torch-hub cache), standardized 768-d CLS features, linear concept head → linear label head on predicted concepts (sequential CBM). Data: local `CUB_200_2011` + Koh-style `class_attr_data_10` pkls; 112 class-denoised labels (verified constant within class on all splits) + 312 raw `is_present` per-image labels parsed from `image_attribute_labels.txt`. Splits: 4796 / 1198 / 5794. Scripts: `scripts/cub_features.py`, `scripts/cub_gate.py`; raw numbers: `data_cache/gate_results.json`.

## Headline results

1. **The 95.2% APS anomaly is the empty-set fill, not train/test shift.** Removing the fill (repo default `fill_empty=True`) returns coverage to nominal under *every* protocol, including the official split. [[03 - Experiments/CUB Same-Pool Coverage Check|Check 1]] is resolved.
2. **The step-2 gate fails as framed**: at matched 90% joint coverage on 112 denoised concepts, the **induced baseline needs 8.5 ambiguous concepts/image vs 55.3 (Bonferroni) and 57.8 (global max)**. Joint concept uncertainty on class-denoised labels collapses into label-set uncertainty.

## Check 1: APS coverage, α = 0.10, no empty-set fill

| Protocol | Coverage | sd | Beta sd | Set size |
| :--- | :---: | :---: | :---: | :---: |
| Same pool, n_cal = 600 (100 draws) | **0.9014** | 0.0128 | 0.0122 ✓ | 2.63 |
| Same pool, n_cal = 3600 (100 draws) | **0.8995** | 0.0085 | 0.0050 | 2.57 |
| Official (cal = 600 from val, eval = test) | **0.9071** | 0.0088 | — | 2.75 |
| Official (heads on 4196, cal = 600 held-out train) | **0.8948** | 0.0083 | — | 2.57 |

Empty-set decomposition (one draw): P(empty) = 0.062, P(top-1 correct | empty) = 0.971 → **+6.0 pts** from filling ⇒ 0.899 → 0.959. The original 95.2% = 0.90 + ~5 pts of the same effect. Residual distribution shift ≤ +0.7 pt (val-cal vs same-pool), within 1 sd.

**Bonus:** temperature scaling (T fit on cal) keeps coverage exact (0.9005) and shrinks sets **2.57 → 1.81**.

## Gate (112 denoised, same-pool n_cal = 3600, 20 draws)

Ambiguous concepts per image at **matched realized joint coverage 0.90**:

| Method | Ambiguous / 112 |
| :--- | :---: |
| **Induced from label sets** | **8.5** |
| Bonferroni | 55.3 |
| Global max (= (m+1), m=0) | 57.8 |
| (m+1), m=1 / m=2 / m=4 / m=8 | 58.2 / 57.9 / 44.5 / 21.9 |
| Uncorrected | ∞ (joint 0.000–0.012 at α ≥ 0.10) |

Induced's joint coverage ≡ its label APS coverage (0.900 vs 0.898) exactly — class-denoised labels are functions of the class, so "all concepts right" **is** "right class". The (m+1) dial behaves exactly as theory says on the weaker claim: m=8 @ α=0.10 gives P(≤8 wrong) = 0.899 with 5.4 ambiguous — still dominated by induced's *all-right* 8.5.

## Verdicts

- **Check 1 ✅ resolved** (fill, not shift) and **D3 settled**: calibrate on same-distribution data, report no-fill coverage (optionally temperature-scaled), state the label source.
- **Step-2 gate ❌ fails** for "efficient uncertainty over the whole concept vector" on CUB-112: nothing beats the induced baseline. Framing must pivot before 10 Nov registration — candidates: (a) the collapse finding itself (label-source dependence of concept-vector uncertainty), (b) raw-annotation setting where induced is not viable and the (m+1)/local-score frontier is the contribution, (c) evaluation-methodology paper (grid + ceilings).
